# Hardware reference

Vendor documentation for the board and panel this firmware targets.

These are links rather than copies. The documents belong to their manufacturers
and are not redistributable under this repository's licence, and they are large
enough to dominate a clone. Download what you need locally; the file names below
are the ones the rest of the documentation refers to.

- `waveshare-esp32-s3-wroom-1-datasheet.pdf` —
  <https://files.waveshare.com/upload/8/87/Esp32-s3-wroom-1_wroom-1u_datasheet_en.pdf>
- `espressif-esp32-s3-datasheet.pdf` —
